# VICE LINE

[![make.fun · gta6-01](https://make.fun/badge/gta6-01.svg)](https://make.fun/bounty/gta6-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-01)

An original, offline open-world arcade crime story set in sunlit Little Havana. Explore on foot or take a car, run jobs, and evade the Vice City police.

**Controls:** WASD move/drive, mouse aim, E enter/exit or steal a car, Shift run, Space melee, F fire, P/Esc pause, C continue a saved game.

Run `node serve.ts` and open http://localhost:8080. The game is static; its small Canvas engine and all game code are local.
